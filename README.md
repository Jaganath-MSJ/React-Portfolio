## About

I'm Jaganath, an Electrical & Electronics Engineering graduate turned web developer, currently shipping React + TypeScript products at Workhall. I build accessible, performant interfaces and publish small open-source utilities on the side.

## Tech Stack

- **React 19 + TypeScript**
- **Vite** — build tool & dev server
- **React Router v7** — routing
- **CSS Modules + design tokens** — no CSS framework, no CSS-in-JS
- **mailto** — contact form opens the visitor's mail client
- **Netlify** — hosting
